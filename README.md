Typecho Theme Fuwari 是一款清新的 Typecho 主题

本主题仅为主题模板，任何的违规违法使用均与本项目无关

### 主题特点

- 使用现代化构建前端
- i18n 多语言支持
- 可自定义主题颜色和横幅
- 目录
- 浅色/深色模式
- RSS/Atom 订阅
